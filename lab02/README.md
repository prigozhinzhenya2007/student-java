## ИНВАРИАНТЫ

### BankAccount:
- Баланс счёта никогда не бывает отрицательным (balance >= 0).
- Счёт нельзя создать с отрицательным начальным балансом (initialBalance < 0 вызывает исключение).
- Пополнять счёт (deposit) и списывать средства (withdraw) можно только на положительную сумму (amount > 0).
- Сумма списания не может превышать текущий баланс (amount <= balance).
- Изменить balance напрямую или через setter нельзя — только через deposit и withdraw.

### ProjectTask
- Идентификатор (id) и название (title) не равны null и содержат хотя бы один непустой символ (!isBlank(), хранятся после trim()).
- Идентификатор (id) задаётся один раз при создании объекта и не изменяется на протяжении всего времени его жизни (final).
- Оценка трудоёмкости (estimatedHours) всегда строго положительная (estimatedHours > 0), при создании не допускаются значения <= 0.
- Увеличивать трудоёмкость (addEstimatedHours) можно только на положительное число часов (additionalHours > 0), уменьшать оценку нельзя.
- При создании задача всегда получает начальный статус TaskStatus.NEW.
- Текущий статус задачи (status) никогда не равен null и изменяется только через метод changeStatus(...).
- Задача считается завершённой (isCompleted() == true) тогда и только тогда, когда её статус равен TaskStatus.DONE.

### TaskStatus
- Множество допустимых статусов задачи строго ограничено константами перечисления (NEW, IN_PROGRESS, DONE).
- Никакое произвольное строковое или числовое значение статуса вне констант TaskStatus существовать не может.
